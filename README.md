# Zoo Management Database
Academic team project developed as part of a Database Systems course.
The project extends an existing Java-based Zoo Management System with a relational database implemented in PostgreSQL.

## Technologies
- Java
- SQL
- PostgreSQL
- JDBC
- Git

## Project Overview
The database models several entities in the zoo management system, including animals, employees, visitors, tickets, promotions, and subscriptions.
The project includes:

- Relational database schema design
- Primary and foreign key relationships
- Data population
- SQL queries using JOINs
- Filtering and aggregation
- Subqueries
- Integration between Java and PostgreSQL using JDBC
